# Sidecut
Укорачивает плавающую панель Zen в компактном режиме и центрирует её по вертикали.
Работает только при включённом Compact Mode (Ctrl/Cmd+Alt+C).

Установка (Sine): Settings → Sine Mods → «add your own locally from a GitHub repo» → ваш репозиторий с этими файлами.
Без Sine: содержимое chrome.css вставить в chrome/userChrome.css профиля, затем about:support → Clear startup cache.
